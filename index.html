中控台使用说明

  1. 主控手柄（左）：把手柄向上推，列车牵引加速，推得越高越快（1–10 档）；推回中间“惰行”档，列车靠惯性滑行；向下拉进入制动，拉得越低刹得越狠（1–7 档）。可拖动旋钮、点击刻度，或在手柄上滚动滚轮。
  2. 速度仪表（中）：指针与数字显示当前时速，最高 350 km/h。
  3. 鸣笛：过站、进隧道前提醒用。声音：点击循环——全部开启（含中文到站播报）/ 关闭播报只留音效 / 静音。临近车站会预告，经过车站会播报“××站到了”。紧急制动：立即最大力度刹车，停稳后再点一次解除。
  4. 定速巡航：自动保持当前速度；用 −10 / ＋10 调整目标速度，再次扳动手柄会退出巡航。
  5. 切换时间：自动昼夜 / 清晨 / 正午 / 黄昏 / 深夜。天气：自动（随地区变化：云南多雨、西藏飘雪、新疆沙尘、江南雷暴……）或手动选晴 / 多云 / 小雨 / 雷暴 / 下雪 / 大雾 / 沙尘。画质：高 / 中 / 低；帧率不够时会自动降档。视角（左上角七个按钮）：驾驶室（3D 驾驶台 + 实时仪表）、车顶、侧面、迎面、俯瞰、车窗（坐在 3 号车厢里看风景）、电影模式（自动切换机位）。
  6. 精准停站（可选玩法）：进站时屏幕上方会出现“停车位置标”的剩余距离、建议制动档位和推荐速度。在站台上的蓝框“停 8”标志处停稳即可评分：误差 ≤0.5 m 为完美停车 ★★★。停稳后自动开门上下客，推手柄即可关门发车。不想停就直接开过去，不扣分；定速巡航时不提示。
